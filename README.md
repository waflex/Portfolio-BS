# Personal Portfolio - Jonathan Rojas

A modern, cyberpunk-themed portfolio website showcasing my professional journey, featured projects, and technical expertise. This dynamic platform allows visitors to explore my work history, download my CV, and easily get in touch with me.

## 🚀 Tech Stack

This portfolio is built with these technologies:

- **[Astro](https://astro.build/)** - For blazing-fast static site generation
- **[Tailwind CSS](https://tailwindcss.com/)** - For utility-first styling
- **[DaisyUI](https://daisyui.com/)** - For beautiful, customizable UI components
- **Font Awesome** - For crisp, scalable icons
- **Custom Cyberpunk Theme** - Featuring neon effects and glassmorphism

## ✨ Features

- Responsive design with a cyberpunk aesthetic
- Interactive project showcase
- Detailed work history
- Contact form integration
- CV download option
- Smooth animations and transitions
- Glassmorphic UI elements
- Neon color accents and hover effects

## 🛠️ Development

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```
